# MEDGRADES — بوابة درجات المعلوماتية الطبية (نسخة Pro)

واجهة عربية متجاوبة RTL لإدارة سجلات الطلاب ومشاهدة درجات المقررات.

## المميزات
- تسجيل دخول الطالب باستخدام رقم قومي تجريبي + هاتف + الفرقة.
- كشف درجات مفصل، مجموع ونسبة وتقدير.
- لوحة إدارة: إحصائيات، بحث بالاسم/الرقم/الهاتف، تصفية حسب الفرقة.
- إضافة وتعديل الطلاب ومقرراتهم، حذف طالب.
- استيراد JSON مع تحقق مبدئي من الهيكل وصحة السجلات والدرجات.
- تصدير نسخة JSON وتقرير CSV مع BOM لدعم العربية.
- حفظ محلي داخل LocalStorage، واستعادة بيانات demo.
- واجهة responsive للموبايل والكمبيوتر.
- GitHub Actions لنشر المشروع إلى GitHub Pages.

## تشغيل محلي
يتطلب Node.js 20+ (على جهازك أو بيئة تطوير أونلاين):
```bash
npm install
npm run dev
```
Build:
```bash
npm run build
npm run preview
```

## النشر على GitHub Pages بدون تثبيت Node.js محليًا
1. ارفع محتويات المشروع إلى مستودع GitHub اسمه `student-grades-portal` على فرع `main`.
2. افتح `Settings → Pages` واختَر `Source: GitHub Actions`.
3. انتقل إلى `Actions` وانتظر نجاح workflow.
4. رابط الموقع المتوقع: `https://amrkhaled40.github.io/student-grades-portal/`.

## تنبيه أمني مهم
هذه نسخة مشروع جامعي/عرض توضيحي، المصادقة وإدارة السجلات تتم على الواجهة وفي LocalStorage فقط. كلمة المرور ليست حماية حقيقية، والبيانات التجريبية قابلة للعرض في كود الواجهة. لا تستخدم أرقامًا قومية أو هواتف أو درجات حقيقية. للإنتاج، يجب بناء API خلفي مع جلسات آمنة وصلاحيات على الخادم وقاعدة بيانات محمية (مثلاً Supabase مع RLS أو PostgreSQL).
